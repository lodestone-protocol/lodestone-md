## 一粒种子的自白

长会话是人机协作的沙地。核心观点在其中滚动，如磁铁球吸附铁粉——有效信息被吸住，歧义与噪声被滤去——但会话历史随之膨胀，结论却应当保持致密。当新会话需要继承旧结论时，重放全部沙地历史是最昂贵也最脆弱的方式。

Lodestone（磁石协议）为这一收敛过程提供登记簿：**节点**（磁铁球）承载脱水后的结论，**边**（磁力线）登记依赖与分歧，**状态机**（draft → converged → aligned）标记球的成型阶段。它定义在标准 Markdown 文件中，以 HTML 注释承载结构元数据，渲染透明，人可直接审计。

本仓库（lodestone-md）是协议的**权威参考实现**：一个确定性解析器 + Golden Fixture 测试套件。协议的第一优先是机器按需加载——L1 骨架先行、L2 定点正文、L3 全文兜底——本实现让这一承诺从文本变为可执行、可验证的事实。

**定位核心：Lodestone Protocol v1.3 的权威参考解析器与协议演进基地。**

## 核心承诺

| # | 承诺 | 含义 | 验收标准 |
|---|---|---|---|
| 1 | 解析确定性 | 输出是文档当前字节的纯函数 | 同一输入任意两次解析输出逐字节一致；Golden Fixture 全绿 |
| 2 | 规范忠实 | 严格实现 v1.3 全部 MUST，SHOULD 尽力 | §11 错误/警告码与规范一一对应；§10 示例数值级吻合 |

**工程铁律（贯穿所有实现）**：逻辑闭环、极致复用、极致解耦、按需获取、按需加载、物理实时优先、确定性优先。

## 哲学七律（所有设计决策的第二裁判，仅次于原子原则）

| # | 哲学 | 在本项目中的落点 |
|---|---|---|
| 1 | **逻辑闭环** | phyt-DNA 治理闭环（PLAN→GROWTH→archive）+ 解析管线单趟闭环：节点表、边、图、诊断出自同一趟结果，互洽无旁路 |
| 2 | **极致复用** | 复用 comrak（CommonMark 0.31.2 成熟实现）而非重造块级解析；Golden Fixture 即协议一致性语料，供一切后续实现复用 |
| 3 | **极致解耦** | 协议与实现解耦（规范是源真相）；模块单一职责（scanner/meta/edges/body/输出契约各自独立）；输出契约冻结，与内部实现解耦 |
| 4 | **按需获取** | body_start/body_end 让任意节点的正文可被定点寻址，无需通读全文 |
| 5 | **按需加载** | L1 骨架 → L2 定点正文 → L3 全文的三级加载是协议原生读取模式，也是本仓库文档生态（RNA 三层加载）的同构原则 |
| 6 | **物理实时优先** | "文件即当前态"模型（§1）：每次解析忠实反映文件当前物理字节，不做缓存、不假设历史、`aligned` 不是内容指纹 |
| 7 | **确定性优先** | 解析输出是文档当前字节的纯函数：无全局状态、固定输出序、依赖图锁定（Cargo.lock 入库） |

## 原子原则（8 条）

以下原则是项目所有设计决策的最高依据。任何代码提交、架构决策、API 变更，若与本原则冲突，以本原则为准。

| # | 原则 | 一句话解释 | 对应规格 |
|---|---|---|---|
| 1 | **确定性优先** | 解析结果是文档当前字节的纯函数，不依赖外部状态 | 规范 §1 |
| 2 | **机器按需优先** | 骨架先行、正文按需，治理长上下文熵预算 | 规范 §1 / §9 |
| 3 | **结构零干扰** | 元数据不产生标题、不进大纲、不进渲染输出 | 规范 §1 / §5.1 |
| 4 | **行为钉死** | 无实现自由度：每条失败路径收敛于唯一既定行为 | 规范 §3.1 / §11 |
| 5 | **CommonMark 锚定** | 节点边界基于 CommonMark 0.31.2 块级解析 | 规范 §4.1 |
| 6 | **延迟绑定** | 局部结论在双端 aligned 前不污染全局图 | 规范 §6 / §7.3 |
| 7 | **容错分层** | 形态层 → JSON 层 → 字段层，失败后果逐层递减 | 规范 §5.3 |
| 8 | **测试即规范之镜** | 每条 MUST/SHOULD 至少一个 Golden Fixture 对应 | 规范建议 E |

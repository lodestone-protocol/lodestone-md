# 安全设计卷（safety）

> **锚定原则**：输入鲁棒性 / 资源上限 / 无副作用解析
> **性质**：白皮书分卷。本实现是纯解析器，无网络、无文件写入、无任意代码执行面。

---

## 1. 输入鲁棒性

解析器面对任意字节输入 MUST NOT panic、MUST NOT 无界消耗资源：

| 威胁 | 防线 |
|---|---|
| 非 UTF-8 输入 | 入口拒绝并返回诊断（协议输入定义为文本文件） |
| 超深嵌套（指数回溯面） | comrak 块级解析为线性扫描；无正则回溯路径 |
| 超长单行 | 线性处理，无每行 O(n²) 算法；重复键预扫描为流式 |
| 巨型文档 | 无内建上限（协议未定义），CLI 层留给调用方；库层文档化声明 |
| 畸形 JSON（深层嵌套） | serde_json 默认递归限制（128 层）兜底，捕获后按 E-META-SYNTAX 处理 |
| 空 slug 炸弹（全符号标题） | E-MISSING-ID 收敛，节点无效 |

## 2. 确定性即安全

协议承诺解析确定性，安全含义：

1. **无 TOCTOU 面**：解析不回读文件、不查时钟、不读环境变量；
2. **无注入面**：输出为结构化数据（serde），诊断 message 中不回显未转义的原始字节片段（仅码点计数与行号）；
3. **无升级面**：`aligned` 状态是作者断言而非安全证明（规范 §1 确定性边界声明）；消费方必须自担跨时间稳定性（钉扎字节用 VCS）。

## 3. 依赖信任边界

| 依赖 | 角色 | 治理 |
|---|---|---|
| comrak | CommonMark 块级解析 | 版本钉死（ADR-0001），升级走 ADR |
| serde / serde_json | 序列化 | 常规审计 |
| unicode-normalization | NFC 检测 | 常规审计 |

Cargo.lock 入库；CI 构建可复现。禁止引入带 build.rs 网络访问或进程生成的依赖。

## 4. 敏感数据

协议文档内容可能含作者私密笔记。解析器为纯函数：不落盘、不上报、不缓存输入。CLI 仅向 stdout 写解析结果。

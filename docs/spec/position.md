# 生态定位卷（position）

> **锚定原则**：权威参考实现 + 生态原生优先
> **性质**：白皮书分卷。

---

## 1. 项目定位

**lodestone-md 是 Lodestone Protocol (MD-DAG) v1.3 Final 的权威参考实现与协议演进基地。**

它不是众多实现之一，而是"一个权威，多种呈现"中的那个权威：其他实现（若出现）以本仓库的 Golden Fixture 为一致性基准；规范修订以本仓库为试点与反馈源头。

## 2. 生态位

| 相邻物 | 关系 |
|---|---|
| 规范文本（Lodestone Protocol v1.3） | 源真相；实现服从规范 |
| phyt-DNA 方法论 | 治理框架；docs/ 是其物化 |
| Obsidian / Markdown 生态 | 消费环境；协议零渲染污染保证兼容（`%%` 等插件语法糖须序列化为 §5.1 规范形态） |
| AI agent 消费方 | 原生用户；L1+L2 为最小合规子集，L3 保留给查全率任务 |
| 其他 MD-DAG 实现 | 以 Golden Fixture 对齐；验证器 MUST 输出一致的错误码/警告码 |

## 3. 独立通用 + 生态原生

- **独立通用**：解析器不绑定任何编辑器、平台、渲染器；输入是字节，输出是 JSON。
- **生态原生**：协议为人机对话的知识脱水而生，实现优先服务机器消费方（骨架 + 按需读取），人类以审查与验收为主（检视 aligned 状态、警告列表、分歧域）。

## 4. 边界（不做什么）

- 不做编辑器、不做渲染器、不做图可视化界面（附录 A 的投影标签是消费方职责）；
- 不做跨文档引用、哈希钉扎、CRDT 合并（v2.0 议程隔离）；
- 不托管协议规范的最终裁决权——规范冲突时实现让位，疑义通过 ADR 上报人类。
